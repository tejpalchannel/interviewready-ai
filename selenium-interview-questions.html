Top 10 Selenium Interview Questions and Answers (2026)

Preparing for a QA automation interview? These are the most commonly asked Selenium interview questions with short, clear answers. Practice them free in InterviewReady AI.

1. What is Selenium?

Selenium is an open-source tool used to automate web browsers. It supports multiple languages like Java, Python, and C#, and is mainly used for UI automation testing.

2. What are the components of Selenium?

Selenium has four components: Selenium IDE (record and playback), Selenium RC (deprecated), WebDriver (browser automation API), and Selenium Grid (parallel testing on multiple machines).

3. What is Selenium WebDriver?

WebDriver is the core of Selenium. It provides APIs to control browsers directly — open pages, click elements, type text, and read page content.

4. What is the difference between findElement and findElements?

findElement returns the first matching WebElement and throws NoSuchElementException if none is found. findElements returns a list of all matching elements, or an empty list if none are found.

5. What is an XPath?

XPath is a way to locate elements in an XML/HTML document using a path expression. It can find elements by attributes, text, or position, e.g., //input[@id='username'].

6. What is the difference between absolute and relative XPath?

Absolute XPath starts from the root (/html/body/...) and breaks easily when the page changes. Relative XPath starts from anywhere (//tag[...]) and is more stable and preferred.

7. What is a fluent wait in Selenium?

FluentWait is a type of wait that polls the DOM at regular intervals until an element appears or a timeout is reached. It lets you ignore specific exceptions while waiting.

8. What is the Page Object Model (POM)?

POM is a design pattern where each web page is represented as a class, with its elements and actions. It makes test code reusable, readable, and easier to maintain.

9. How do you handle dynamic elements in Selenium?

Use dynamic XPath strategies such as contains(), starts-with(), or text() functions, and combine them with explicit waits so the script waits for the element to be ready.

10. How do you handle pop-ups and alerts in Selenium?

Use driver.switchTo().alert() to switch to JavaScript alerts, then accept(), dismiss(), or sendKeys(). For browser-level pop-ups, use browser options or third-party tools.

Free Selenium Interview Questions

Short, clear answers you can read in a minute. Open a question to see the answer.

What is the difference between findElement and findElements?

findElement returns the first matching element and throws NoSuchElementException if none is found. findElements returns a list of all matching elements, or an empty list if none are found, so it's safer when an element may not exist.

What is the difference between absolute and relative XPath?

Absolute XPath starts from the root, such as /html/body/div[2]/form/input, and breaks whenever the page structure changes. Relative XPath starts anywhere, such as //input[@id='username'], and is more stable, so testers prefer it.

What is the difference between implicit and explicit waits?

An implicit wait applies to every element lookup for the whole session. An explicit wait pauses only for a specific condition, such as an element becoming clickable, and it's usually the better choice because it's more precise.

What is the Page Object Model (POM)?

POM represents each web page as a class that holds its locators and actions. Tests call those methods instead of locators directly, so when the UI changes, you update one class, not every test.

How do you handle a JavaScript alert in Selenium?

Switch to it with driver.switchTo().alert(), then call accept() to click OK, dismiss() to click Cancel, or sendKeys() to type into a prompt, and use getText() to read the message.

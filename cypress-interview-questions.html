Top 10 Cypress Interview Questions and Answers (2026)

Most asked Cypress interview questions with clear, short answers. Practice them free in InterviewReady AI.

1. What is Cypress?

Cypress is a JavaScript-based end-to-end testing framework that runs directly in the browser, making tests fast and easy to debug.

2. How is Cypress different from Selenium?

Cypress runs in the same browser as the app (no WebDriver), has automatic waiting, time travel debugging, and is limited to JavaScript. Selenium supports more languages and browsers.

3. What is the difference between cy.get() and cy.contains()?

cy.get() finds elements by CSS selector. cy.contains() finds elements by their text content.

4. What is Cypress's automatic waiting?

Cypress automatically waits for commands and assertions to complete before moving on — no manual sleeps needed for most cases.

5. What is cy.intercept()?

cy.intercept() is used to spy, stub, or mock network requests and responses in tests.

6. What is a fixture in Cypress?

A fixture is a fixed set of data (JSON, etc.) loaded with cy.fixture() to use as test input, keeping test data separate from test code.

7. What is the difference between cy.request() and cy.intercept()?

cy.request() makes an HTTP request directly from the test. cy.intercept() intercepts and controls network requests made by the app.

8. What are Cypress custom commands?

Custom commands are reusable functions added to Cypress (Cypress.Commands.add) to avoid repeating code, like a custom login command.

9. What is the difference between .then() and .should()?

.then() lets you work with the yielded value (like a callback). .should() makes an assertion and automatically retries until it passes or times out.

10. What is Cypress time travel?

Time travel shows snapshots of the app at each command step in the Test Runner, letting you see what the app looked like before and after each action.
